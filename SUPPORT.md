# Support

Orbit is an open-source, Cursor-hosted ticket agent.

## Supported

- Config + schema questions
- Skill/script bugs
- Documentation gaps

## Not supported (v1)

- Guaranteeing correct implementations for arbitrary tickets
- Operating your Jira/Confluence/MCP/cloud accounts
- Background/unattended daemon mode
- Auto-merge workflows

## Where to get help

- GitHub Issues for bugs/features
- Read `docs/presentation-faq.md` for skill-vs-system questions
